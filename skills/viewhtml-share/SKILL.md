# ViewHTML 网页分享

把用户指定的网页发布为公开的预览页 `https://viewhtml.app/share/{id}`。分享页以预览容器展示渲染结果。

**有效期取决于有没有账号：**

- **匿名发布**（本技能默认的方式，不需要登录）：链接**只有 3 天有效期**，3 天后失效并被删除，也不能再更新。
- **发布到用户的账号**（用户提供了含 `Authorization: Bearer vh_…` 的提示词，见下文「发布到用户的账号」）：页面归用户所有，按用户的套餐保留，没有 3 天限制；免费账号永久保留 3 个页面，Pro 不限数量，可以更新、保留历史版本、上传图片和文件。

## 适用范围

- 适用于一个可独立打开的 `.html` 文件，或用户直接提供的完整 HTML。
- 不适用于需要服务器、登录态、私有 API、构建时路由或多个本地资源才能正常工作的应用；这类需求应使用项目的实际部署方式。
- 不要把含凭据、个人信息、内部链接、未公开业务数据或版权受限素材的内容提交到该公开服务。

## 发布前

1. 确认要分享的确切 HTML。若用户只指向一个项目目录，先找出其可独立打开的产物；没有明确产物时询问，不要猜测上传哪个文件。
2. 检查文件不超过 2 MB，并审阅其中是否含敏感信息。页面中的图片、样式和脚本应内联，或使用公开可访问的绝对 HTTPS URL；本地相对资源不会随 HTML 一起上传。
3. 如果用户没有明确要求公开分享，或内容的公开性不清楚，先说明链接是公开的（匿名发布 3 天后失效）并征求确认。

## 发布

将 HTML 以 JSON 提交到 ViewHTML。`url` 任务同步完成，成功响应的 `result.url` 就是最终链接：

```bash
curl --fail-with-body --silent --show-error \
  -X POST https://viewhtml.app/api/jobs \
  -H 'Content-Type: application/json' \
  --data-binary "$(jq -n --rawfile html /absolute/path/page.html '{type: "url", html: $html}')"
```

先使用 `jq` 检查响应的 `status` 为 `succeeded`、`result.kind` 为 `url`，再读取 `result.url`。不要自行拼接 URL 或依赖内部子域名。

同一份 HTML 在有效期内会复用同一个分享链接（已过期的不会复用）；不同内容会获得新的 12 位 Base62 ID。每个来源 IP 有每日额度，收到 `429` 时停止重试并告知用户重置时间。成功响应里的 `result.expiresAt` 是匿名链接的失效时间。

## 发布后验证与交付

对 `result.url` 发起一次 `GET`，确认返回 `200` 且页面内容是分享容器；不要把来源 HTML、内部 iframe 地址或任何敏感内容放进最终回复。向用户交付公开分享链接，并简要说明它来自哪个本地文件。匿名发布时必须告诉用户：这个链接 3 天后失效，想长期保留需要在 viewhtml.app 登录后发布。

若请求失败：

- `400`：修正 HTML 为空、超过 2 MB 或请求结构不对的问题。
- `429`：等待响应中的重置时间，不能通过重试绕过额度。
- 网络或 5xx：只重试一次；仍失败则报告错误，不要假称已发布。

## 发布到用户的账号

用户在 ViewHTML 登录后，点「Copy prompt」得到的提示词里带着一个以 `vh_` 开头的凭证。拿到这样的提示词时，**按提示词里写的接口发布，不要用上面的匿名方式**：

- 发布新页面：`POST /api/pages`，请求头 `Authorization: Bearer vh_…`，请求体 `{"html": "…"}`；响应里的 `shareUrl` 就是要交付的链接。
- 更新页面：`POST /api/pages/{id}/versions`，链接不变。
- 图片、音频、视频：`PUT /api/pages/{id}/assets/{文件名}`，请求体是文件内容，响应给出文件的绝对地址，写进 HTML 后再发布新版本。
- 先用 `GET /api/me` 查看用户的套餐和剩余空间。
- 这个凭证是用户的私有凭证：不要写进发布的页面、代码仓库或日志。
